  ┌──────────────────────────────────────────────────────────────────────┐
  │  1.  CONTROLS TO KNOW BY HEART                                       │
  └──────────────────────────────────────────────────────────────────────┘

    "stop"  ·  "abort job"              stop whatever JARVIS is doing
    "are you okay"                      JARVIS status card
    "did that work?"                    check the last action
    "is that done?"                     check a command left in a terminal
    "that's not what I said"            unlearn a wrong match  ★ use often
    "do that again"                     repeat the last skill

    "be quiet for a while"              voice off for now
    "be silent from now on"             voice off until you say otherwise
    "speak again"                       voice back on
    "show / hide what you hear"         see what JARVIS heard
    "open / close the chat"             the chat window
    "close it"                          close the card on screen
    "bring back the orb"                the orb  ("get the orb out of the way")
    "refresh your settings"             reload config         (/reload)
    "list your commands"                the built-in list     (/list)

    /sys     command list only, no AI
    /agent   command list first, then Claude
