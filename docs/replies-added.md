# What JARVIS says, and the lines we added

JARVIS picks one line at random from each list and never says the same one twice in a row. Each entry: **was** = the lines from before 2026-11-12, **added** = added 2026-11-12, ✨ **new** = added 2026-11-13, ✏️ **replace** = a line swapped for a better one on 2026-11-13. All of them are in the code. `{name}` is what JARVIS calls you, `%s` / `%d` / `{app}`... are filled in.
